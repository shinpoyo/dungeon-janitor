# 2026-10-28 第2版：暗闇と冒険の書、勇者の一歩先で直す

## ユーザーの感想（第1版）

- 段取りは面白い
- 見届けるのは、面白くなりそうで面白くない
- 見つけるのは、全部見えているので面白みがない

## 何を変えたか

### 見つける → 暗闇と冒険の書で推理する

- フロアを暗くした。見えるのは清掃員のランタン（半径 2.6）と、灯っている松明（半径 3.6）の届く所だけ。一度見た所は薄暗く残る
- 前の勇者の「冒険の書」を最初に読む。部屋ごとに「がいこつを倒した」「罠にかかった（2回）」「火の魔法をぶっぱなした」などが書いてあるが、場所は書いていない。1 ページは破れていて読めない
- 設計図（あるべき配置）と冒険の書を突き合わせると、「この部屋の罠は 2 つ、かかったのは 1 回 → どちらかを見に行く」と当たりがつけられる。松明を先に灯すと部屋が見渡せる

### 見届ける → 勇者が来ても仕事が続く。見つかってはいけない

- 勇者が来たあとも清掃員は動ける。勇者が通るのは 1→5 の決まった順の部屋なので、その先の部屋を直しに行ける
- ただし勇者と同じ部屋にいると「今の誰！？」で見つかり、ワクワクが下がる。見つかると清掃員は自動で職員通路へ逃げる
- 左に職員通路を作った。点線の隠し戸（勇者には壁）から各部屋の横に出られるので、先回りに使う
- 蘇生札は貼ってから起き上がるまで 8 秒かかる。勇者が来る少し前に貼る段取りが要る

### 評価 → 「直すほど良い」をやめて「ちょうどいい」にした

- 勇者に体力（10）とワクワク（60 から）を持たせた。スライムは体力 −1・ワクワク +12、がいこつは −2・+18、罠は −1・+8、宝は +10〜15（薬草は体力 +3）。何も起きないと毎秒 −1.6
- 体力 0 で神殿送り、ワクワク 0 で帰宅、どちらも失敗。階段まで行けば成功で、ワクワクで星が決まる。体力 3 以下で着くと「ギリギリの冒険だった！」で +15
- 倒れたモンスターは、蘇生札なしで触ると片付けられる。全部起こすと勇者が倒れるので、どれを起こしてどれを片付けるかが加減のしどころ

## 測ったこと（自動プレイ）

全部の配置を知っている自動プレイで、同じフロアを何度か遊ばせた。

| 遊び方 | 結果 |
|---|---|
| 何もせず勇者を呼ぶ | 退屈して帰る |
| 近い順に直す（準備 75 秒・退屈 2.2/秒のとき） | 3 回とも退屈して帰る（直しきれない） |
| 全部を直す（準備は 43〜68 秒で終わる） | 6 回とも勇者が倒れる（体力 0） |
| 後半の部屋のがいこつだけ片付け、ほかは直す | 3 回とも成功・体力 3・星 3 |

「何もしない」「全部直す」のどちらも失敗し、加減したときだけ星 3 になる形になった。最初の設定（準備 75 秒、ワクワク 50 から、退屈 2.2/秒）は厳しすぎたので、準備 90 秒・60 から・1.6/秒にした。自動プレイは場所を全部知っているので、人は暗闇を探す分だけ時間がかかる。

## 確かめたこと

- `npx tsc --noEmit`・`npx vite build` が通る
- Playwright で 360×740 と 1366×768 を表示し、引き継ぎ → 準備 → 棚 → 設計図 → 勇者 → 評価 まで通した。コンソールのエラーなし

## 気になっていること

- ワクワクが 100 で頭打ちになりやすく、成功すれば星 3 になりがち。星の基準か上限は、人が遊んだ感想を見て直す
- 冒険の書が正確すぎるかもしれない（嘘や大げさな書き方を混ぜる案がある）
- 勇者が来ても暗い部屋は暗いまま。勇者の明かりで見えたものは「見た」扱いになる
