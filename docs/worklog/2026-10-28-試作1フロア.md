# 2026-10-28 1 フロアの試作を作った

## やったこと

- 企画（`ダンジョンの清掃員`）の芯になる 3 つ（見つける・段取る・見届ける）を、1 フロアで遊べる形にした
- 作業は 6 種類：モンスター蘇生（蘇生札、8 秒で起き上がる）・宝箱の詰め直し（薬草・銀の剣・金貨。深さで正解が決まる）・罠の再設置・松明・汚れ（血・焦げ・落書き）・扉の修理（板）
- 前の勇者の荒らし方は乱数の種から作る。「同じ現場でもう一度」は同じ種で遊び直せる（あとで日替わりにも使える）
- 勇者は入口から、まだ見ていない物へ近い順に回って階段へ向かう。罠にかかる・空の宝箱に落ち込む・倒れたままの敵に戸惑う、などの反応を吹き出しで出す
- 評価は勇者が入った瞬間の状態で決める。同じ感想はまとめて「×3」と出す

## 決めたこと・理由

- 世界観は DungeonHelloween とつなげない（ユーザーの判断）
- ゲーム用ライブラリは使わず Canvas に直接描いた。試作の段階では絵を差し替えやすく、読み込みも軽い（JS 約 25KB）
- 勤務時間は 100 秒。近い順に回るだけの自動プレイで、28 か所すべて直すのに約 84 秒かかった（倉庫の操作も含む）。人は設計図を見たり迷ったりするので、全部は直しきれない程度にした

## 確かめたこと

- `npx tsc --noEmit`・`npx vite build` が通る
- Playwright で 360×740 と 1366×768 を表示し、出勤 → 倉庫 → 作業の予約 → 設計図 → 勇者 → 評価 まで通した。コンソールのエラーなし
