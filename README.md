# ダンジョンの清掃員（試作）

勇者が荒らしたダンジョンを、次の勇者が来るまでに「初めて来たように」戻す、RPG の裏方を遊ぶブラウザゲームです。

いまは **1 フロアだけの試作** です。「見つける（設計図と見比べる）・段取る（限られた時間と持ち物で順番を決める）・見届ける（直したフロアを勇者が進むのを見る）」の 3 つが面白いかを確かめるためのものです。

## 遊び方

1. マスをタップすると、清掃員がそこへ行って作業します（6 つまで予約。もう一度タップで取り消し）
2. 倒れたモンスターには蘇生札、壊れた扉には板、空の宝箱には中身が要ります。左上の倉庫の棚で取ってきます（3 つまで）
3. 宝箱に何を入れるかは「設計図」に書いてあります
4. 時間（100 秒）になるか「勇者を呼ぶ」を押すと勇者が来て、反応で仕事が評価されます

## 動かし方

```bash
npm install
npm run dev     # 開発サーバ
npm run build   # 型チェック＋ dist/ に出力
```

素の TypeScript + Vite + Canvas で、ゲーム用のライブラリは使っていません。

| ファイル | 役割 |
|---|---|
| `src/map.ts` | フロアの設計図（文字で書いた地図）と経路探索 |
| `src/game.ts` | 荒らし方の生成、清掃員・勇者の動き、評価 |
| `src/render.ts` | Canvas への描画（絵はすべてコードで描いている） |
| `src/main.ts` | 入力・画面の表示・ループ |

動作確認用に、ブラウザのコンソールから `window.__dj.game` で今の状態を見られます。
