# ダンジョンの清掃員（試作）

勇者が荒らしたダンジョンを、次の勇者が来るまでに直す。ただし直しすぎると勇者が倒れ、直さなすぎると勇者が退屈して帰る。
RPG の裏方として、勇者に「ちょうどいい冒険」をさせるブラウザゲームです。

いまは **1 フロアだけの試作** です。

## 遊び方

1. **引き継ぎ**：前の勇者の「冒険の書」を読む。部屋ごとに何をしたか（敵を倒した・罠にかかった・松明を蹴り倒した…）は書いてあるが、どこでかは書いていない
2. **準備（90 秒）**：フロアは暗く、ランタンの届く所しか見えない。冒険の書と設計図から当たりをつけて回り、直す。蘇生札・板・宝箱の中身は職員通路の棚で取ってくる（3 つまで）
3. **本番**：勇者が入ってくる。仕事は続けられるが、**勇者と同じ部屋にいると見つかる**。点線の隠し戸から職員通路を通って先回りする
4. **評価**：勇者は戦うと体力が減り、敵・罠・宝でワクワクが上がり、何もないと退屈する。体力 0 で神殿送り、ワクワク 0 で帰宅。ギリギリで階段にたどり着くのが最高の仕事

倒れたモンスターは、蘇生札を持っていれば起こし、持っていなければ片付ける（勇者に「もう倒れてる…」と言わせないための手）。

## 動かし方

```bash
npm install
npm run dev     # 開発サーバ
npm run build   # 型チェック＋ dist/ に出力
```

素の TypeScript + Vite + Canvas で、ゲーム用のライブラリは使っていません。

| ファイル | 役割 |
|---|---|
| `src/map.ts` | フロアの設計図（文字で書いた地図）、部屋分け、経路探索、見通し |
| `src/game.ts` | 荒らし方と冒険の書の生成、明かり、清掃員・勇者の動き、見つかる判定、評価 |
| `src/render.ts` | Canvas への描画（絵はすべてコードで描いている） |
| `src/main.ts` | 入力・画面の表示・ループ |

動作確認用に、ブラウザのコンソールから `window.__dj.game` で今の状態を見られます。
